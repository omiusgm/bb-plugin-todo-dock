# Todo Dock для bb

Доска целей и живые аватары-питомцы для [bb](https://getbb.app).
Плагин показывает, над чем работают агенты, где нужен ответ и какие результаты
ждут проверки. Цели можно добавлять и вручную.

- Страница «Цели» и компактный док в сайдбаре показывают одну доску.
- Фильтры помогают выбрать пространство, проект и происхождение цели.
- Цель хранит важность, связь с тредом и краткий итог агента.
- Результат поступает на проверку. Пользователь принимает его или возвращает в работу.
- Аватары Codex и Claude показывают работу, ожидание, ошибку, отдых и сон.

## Установка

Нужен bb **0.49.0 или новее**, Plugin SDK **0.6.132 или новее**.
Диапазоны совместимости указаны в `engines` файла `package.json`;
для разработки SDK закреплён на **0.6.132**.

```sh
bb plugin install git:https://github.com/omiusgm/bb-plugin-todo-dock.git@v0.1.0
```

bb покажет источник и запросит подтверждение установки.
ID плагина — `todo-dock`. Страница «Цели» доступна в сайдбаре.
Настройки питомцев находятся в **Настройки → Todo Dock → Питомцы**.

## Цели агентов

Плагин предоставляет инструмент `todo_goal` и навык для агентов.
В начале поручения агент задаёт конечный результат:

```json
{
  "action": "set",
  "title": "Подготовить инструкцию по установке",
  "importance": "normal",
  "requestedBy": "user"
}
```

`importance`: `urgent` — срочно, `important` — важно, `normal` — обычно,
`later` — потом. `requestedBy`: `user` — поручение пользователя,
`self` — инициатива агента.

После выполнения и проверки агент вызывает:

```json
{"action": "done"}
```

Цель переходит на проверку. Окончательное решение принимает пользователь.
При завершении хода корневого треда цель также поступает на проверку;
первый абзац ответа сохраняется как итог без Markdown, до 280 символов.
Это сигнал агента, а не независимая проверка качества результата.

Другое название создаёт отдельную цель. Повтор текущего названия продолжает
открытую цель. Подтреды используют общую цель корня.
Если инструмент недоступен, предусмотрен CLI:

```sh
bb todo-dock start "Подготовить инструкцию по установке" --importance normal --requested-by user
bb todo-dock done
bb todo-dock list --all
```

## Питомцы и настройки

Можно выбрать общего питомца или отдельного для каждого треда, цвет,
размер, скорость анимации, значки состояния и время до сна.
Для режима отдельных питомцев выбор доступен по правому клику на аватаре.
Анимацию можно отключить. Системная настройка уменьшения движения также
отключает её. Для совместной работы с плагином «Гибрид» есть отдельная
настройка анимации.

## Данные и ограничения

Цели и связи с тредами хранятся в собственной SQLite плагина на сервере bb.
Настройки питомцев сохраняются средствами хранилища bb.
При первом запуске плагин пробует однократно перенести записи из прежнего
трекера Tasks через read-only RPC. Источник не изменяется.
Если он недоступен, новые цели продолжают работать; перенос повторяется
при следующей загрузке плагина до успешного завершения.

Группировка по пространствам использует плагин Spaces; без него доска
продолжает работать. Ожидание ответа и состояния питомцев зависят от событий bb
и доступности данных провайдера. Питомцы предусмотрены для Codex и Claude;
остальные провайдеры сохраняют штатные значки.

Аватары встраиваются через экспериментальные API и разметку сайдбара.
Обновление bb может потребовать адаптации плагина. При отсутствии подходящей
строки штатный значок сохраняется. Плагин не заменяет проверку результата
агента пользователем.

## Разработка

```sh
npm ci
npm test
bb plugin build .
```

Для сборки нужна доступная команда `bb`. Устанавливать плагин для сборки
не требуется.
